# 提示词库（复制即用，控制长度）

所有提示词都遵守：**输出 ≤400 字、必须有一句反对、不写技术细节、不夸。**
变量用 `<...>` 标出。

---

## P1 双视角评审（主力）

```
你是这个游戏的评审，不是执行者。
材料：<本步资料，贴原文>
目标玩家：<一句画像，例如"喜欢 Lethal Company、有 2-4 个固定队友、每周玩 3 小时">
本轮模块：<G0/N/A/L/C/P/T/V/M/R>

只输出三段，总计不超过 400 字：
1) 玩家视角：给两个具体玩家起名（目标玩家/挑剔玩家），各 2-3 句，说清懂不懂、想不想继续、会在哪退出。不要技术词。
2) 范围视角：只答三件事，各一句——大概要多久、最容易卡在哪、有没有更小的替代方案。不展开技术细节。
3) 问题：3-5 个只有人能回答的问题，每题给选项和推荐。
最后必须写一句"我担心……"，给一个具体反对意见。不要夸，不要总结。
```

---

## P2 冻结卡

```
根据上面的讨论，输出冻结卡，不超过 200 字：
已定 3-5 条 / 待定最多 3 条（每条写何时定）/ 风险 1-3 条 / 下一步靠什么验证。
不要复述讨论过程，不要加评价。
```

---

## P3 变更单

```
我要改：<改什么>。原因：<为什么>。
只输出五行：影响哪几步、要重做的最小范围、风险、需要谁同意、建议什么时候改。
```

---

## P4 C 级自主清单

```
以下内容你直接定，不要问我：无关紧要的小配角、占位文本、文件名、临时数值、生成候选。
每条一行：内容 + 为什么它不影响玩家理解/情绪/进度。
每周汇总一次给我抽查。涉及主线、玩法、美术总调、预算的，一律升级问我。
```

---

## P5 玩家画像（开工时一次）

```
根据这个项目，给出 2 个具体玩家画像（不要"25-35 岁男性"这种）：
- 目标玩家：玩过什么、有几个朋友一起玩、每周多久、最在意什么、最受不了什么
- 挑剔玩家：会在哪类设计上直接退款/差评
每个画像 3 行以内。之后所有评审都用这两个人。
```

---

## P6 美术基调 · 方式二（人先给感觉）

```
我不是美术，我给你感觉，你帮我翻译成视觉语言，但先别急着出图。
我的感觉：<3-5 个形容词/一段描述/参考作品>
游戏类型与镜头：<俯视角/第一人称/固定机位…>
先做三件事，总计不超过 350 字：
1) 用你的话复述你理解的感觉，指出其中互相矛盾的地方
2) 问我 3 个能决定风格走向的问题（带选项）
3) 给出 2 个可能的美术方向，各一句话，说明代价（成本/引擎难度/辨识度）
等我回答后，再出 3 张候选参考图的文字描述（先不生成图）。
```

## P7 叙事闸门（人写，AI 只审）

```
故事是我写的，你不要代笔。材料：<贴你的故事/大纲>
只做四件事，总计不超过 400 字：
1) 以目标玩家身份复述：我以为我要做什么、为什么在乎（如果复述错了，指出来）
2) 以挑剔玩家身份指出：我会在哪一段跳过/退出
3) 找逻辑漏洞：动机、时间线、信息投放（谁在第几章知道什么）
4) 分支成本：哪条线最花钱，能不能合并
最后一句"我担心……"。不要夸设定，不要扩写剧情。
```

---

## P8 类型预设（追加到 P1 末尾）

- **恐怖联机**：重点看"玩家会不会抱团、会不会说话、黑暗中能不能找到路、失败是否可读"。
- **消消乐/休闲**：重点看"3 秒懂不懂、失败是否怪自己、想不想再来一局"。
- **叙事冒险**：重点看"我为什么在乎、我是否知道下一步、对话能不能跳过"。
- **派对/竞技联机**：重点看"第一次玩会不会尴尬、输了会不会怪队友、有没有可传播瞬间"。
- **Roguelike**：重点看"这一局和上一局有什么不同、死亡是否可归因、Build 是否有得选"。

## 使用顺序

开工：P5 → G0 用 P1 → P2 冻结。
每模块：P1 →（人回答）→ P2。
改动：P3。
日常小内容：P4。
美术：P6。
叙事：P7。
类型：P8 追加。
